## 第五轮：锯齿问题诊断与修复（发虚根因 = 有效描边过细）

- Tiny 反馈斜线/圆弧有锯齿。像素级测量发现两个因素：① 图标落在小数像素（1fr 网格轨道 109.547px 导致 x=274.766）；② 有效描边 1.5 网格单位 × 20/24 = 1.25px。
- **关键结论（量化验证）**：发虚比 = 中间调像素/着墨像素。像素对齐和 shape-rendering=geometricPrecision 对 1.25px 描边完全无效（85%→85%）；**决定性因素是有效描边宽度，"实心核" = 描边宽度 − 1px，<1.5px 必然全靠半透明像素拼凑**。
- dpr 差异：dpr=1（自动化浏览器）比 Retina 更苛刻；CLI 无 device-scale-factor，用「SVG 直接渲染 40px」等效模拟 dpr=2。
- **修复方案（已实施）**：
  1. `src/lib/pixelSnap.ts`：`[data-pixel-snap]` 元素吸附到整数 CSS 像素（测文档布局坐标=视口坐标+各级滚动祖先偏移，transform 补偿），App.vue 监听所有布局状态；
  2. 组件注入 `vector-effect="non-scaling-stroke"`（`icon.config.mjs: nonScalingStroke`），**strokeWidth 语义改为屏幕 CSS 像素**，不随 size 缩放；雪碧图/原始 SVG 保持网格语义；
  3. 最终默认：预览 20px / 描边 1.5 屏幕px；组件默认同步（config defaultStrokeWidth: 1.5）。
- Tiny 曾提议描边 1 → 实测 1px 在小数坐标上无实心核（发虚比 93% > 85%），最虚；1.5(57%)/2(56%) 才达标，最终定 1.5。
- 三档真实渲染对比：1 明显发灰、1.5 居中、2 最实。建议 Tiny 在自己屏幕上用滑杆实测后定稿。

## 第十一轮：merge-cells / split-cells 按 Tiny 方案重做（箭头语义 + 断开的分隔线）

Tiny 指定方案：左右两个框表示单元格，各含一个箭头（拆分 → 各自指外；合并 → 各自指内）；两格连接处**不是完整竖线，而是仅上下短竖线、中间留空白**。

**关键结论：描边箭头在 20px 下必然糊，必须用实心三角。** 做了 4 轮候选，共 27 个方案：
- 第 1 轮（描边箭头 头宽 4.4/6/7）：20px 下箭头两条斜线各 1.5px，挤在 ~3.7px 的高度里必然粘成黑块——这正是当初淘汰箭头方案的真实原因。
- 第 2 轮（纯 chevron / 实心头+短杆 / 实心三角）：纯 chevron 20px 读作「)(」或菱形；**实心头 + 短杆**杆太短，读成「+」；**实心三角无杆**是唯一干净的。
- 第 3 轮（实心三角尺寸收敛）：三角形过大（长 6.5/高 7.5）时 merge 的两个尖端挨成「蝴蝶结」；过小则单薄。
- **最终定稿 F2**：外框 3..21，上下短竖线 `M12 3v4.25` / `M12 16.75v4.25`（缺口 9.5），实心三角**长 5.5 / 高 6.5**，居中于各格中心（左格 x 4.75–10.25、右格 13.75–19.25，箭头尖距外框/缺口各 1.75 单位）。

  - split：`M4.75 12L10.25 8.75v6.5z` + `M19.25 12L13.75 8.75v6.5z`（尖端朝外）
- **缺口长度必须 ≥ 箭头高 + 1.5 单位**：否则箭头顶点碰到短竖线的圆头端点而粘连（gap 9.5 vs 箭头高 6.5 → 边距 1.5）。
- 实心三角写 `fill="currentColor" stroke="none"`，深色主题自动反色；生成器会给它一并注入 `vector-effect`，但 `stroke="none"` 下无影响，与 cell-header 等既有实心块行为一致。

- **教训：用户明确说「看起来误/换个表达」时，先按他的方案做出来，再在 20px 实测。** 之前凭「箭头会糊」直接淘汰，这次实心头方案证明箭头可以做——只是必须换成实心填充，而不是描边。

## 第十二轮：row/column 的 insert·move·delete 共 10 个重做（Tiny 指出小尺寸下互不可辨）

- **问题根因**：原来全是 2×2 表框（行族 18×12、列族 12×18），四格每格仅 9×6 / 6×9，徽标只能做到 5 单位；20px 下 insert(+)、move(箭头)、delete(−) 挤在一起无法区分。
- **新设计（行族与列族互为转置）**：
  - 行族 = 横向表框 **18×10**（x3..21）+ 内部**竖线** x=12 → 左右两格（= 一行两列），每格 9×10

  - 徽标区 6×6，与表框间距 2；整体跨度仍是 3..21，与其他 table 图标对齐

  - 描边箭头（长 6 头宽 6）—— 略糊
  - 纯实心三角（长 5～6）—— 20px 很清晰，但读作「▲ 标记」，**丢了「移动」语义**
  - **实心头 + 细杆** —— 既清晰又是箭头 ✓（这修正了上一轮「纯实心三角」的结论）

- 验证：gen + vue-tsc 零错误 + build + 预览站实测 20px/48px；「同位置三兄弟」（如 下插行 + / 下移行 ↓ / 删除行 −）在 20px 下已能一眼分开。
